# Main Idea

Users can upload documents and chat with them using AI and everything is user specific.

Supported files:

* PDF
* DOCX
* TXT

Example:

```text
Upload Employee Handbook.pdf

        ↓

Extract text

        ↓

Split into chunks

        ↓

Generate embeddings

        ↓

Store embeddings in pgvector

        ↓

User asks a question

        ↓

Semantic search

        ↓

Retrieve relevant chunks

        ↓

Send context to Gemini

        ↓

AI answer + sources
```

```typescript

```

Store the embeddings in PostgreSQL using pgvector.

---

# Semantic Search

When the user asks:

```text
"What is the company's leave policy?"
```

Do:

```text
Question
   ↓
Generate embedding
   ↓
pgvector similarity search
   ↓
Get top 5-8 relevant chunks
   ↓
Send chunks to Gemini
```

Make sure search is restricted to the logged-in user's documents.

---

# RAG

Create a dedicated `RagService`.

Flow:

```text
Question
   ↓
Embedding
   ↓
Vector Search
   ↓
Relevant Chunks
   ↓
Context
   ↓
Gemini
   ↓
Answer
```

Use a system prompt similar to:

```text
You are DocMind, an AI assistant that answers questions
about the user's documents.

Use the provided document context to answer the question.

Do not invent information.

If the answer cannot be found in the provided documents,
say that you could not find the answer.

Always provide useful source information when available.
```
